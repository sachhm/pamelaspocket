# Pamela's Pocket

The app is in `flutter/`. It keeps its data on the phone.

Install Flutter with Dart 3.12 or newer:
<https://docs.flutter.dev/get-started/install>

On a Mac, install Xcode and open it once to accept the license.

```bash
cd flutter
flutter pub get
flutter run
```

Connect an iPhone, or open the iOS Simulator, before `flutter run`.
`flutter devices` lists what Flutter can see.
